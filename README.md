# La Biblia Abierta

**Una plataforma minimalista para encontrarse con Cristo en la Palabra revelada**

Un proyecto de promoción del evangelio y literatura saludable basado en las enseñanzas de Watchman Nee y Witness Lee. *La Biblia Abierta* es un espacio de estudio bíblico diseñado para tres tipos de audiencias:

1. **Inconversos que desean conocer a Dios** — Explora las verdades fundamentales del evangelio
2. **Nuevos creyentes** — Recibe nutrición espiritual y enseñanza práctica para tu nuevo caminar
3. **Creyentes avanzados** — Profundiza en la vida divina, la vida de iglesia y la revelación progresiva

---

## 🎨 Diseño

### Filosofía
Minimalismo intencionado. Cada elemento existe para servir un propósito — guiar al usuario hacia su camino de encuentro con Cristo.

### Paleta de Colores
- **Blanco/Crema**: Fondos limpios y claros
- **Azul marino** (`#1a3a52`): Texto principal, confianza y profundidad
- **Verde sage** (`#6b8e71`): Acentos y llamadas a acción, vida espiritual
- **Gris pizarra**: Textos secundarios y sutileza

### Tipografía
- **Fraunces**: Títulos (serif editorial, elegante)
- **Source Serif 4**: Cuerpo de texto (legibilidad, calidez)
- **Inter**: UI y etiquetas (funcional, moderno)

## 🚀 Publicar en GitHub Pages

### Opción 1: Crear un nuevo repositorio desde la CLI

```bash
# Clona este directorio a tu máquina local (o descárgalo)
cd la-biblia-abierta

# Inicializa git (si no lo has hecho)
git init

# Configura tu usuario
git config user.name "Tu Nombre"
git config user.email "tu.email@example.com"

# Añade todos los archivos
git add .

# Realiza el primer commit
git commit -m "Initial commit: La Biblia Abierta landing page"

# Cambia la rama a 'main' (recomendado)
git branch -M main
```

### Opción 2: Crear repositorio en GitHub y conectar

1. **Ve a [github.com](https://github.com) y crea un nuevo repositorio**
   - Nombre: `la-biblia-abierta` (o lo que prefieras)
   - Descripción: "Una plataforma minimalista para encontrarse con Cristo en la Palabra revelada"
   - Visibilidad: **Public**
   - NO inicialices con README (ya lo tenemos)

2. **Conecta tu repositorio local al remoto**
   ```bash
   git remote add origin https://github.com/TU_USUARIO/la-biblia-abierta.git
   git branch -M main
   git push -u origin main
   ```

### Opción 3: Habilitar GitHub Pages

1. En tu repositorio en GitHub, ve a **Settings** → **Pages**
2. Selecciona:
   - **Source**: `main`
   - **Folder**: `/ (root)`
3. Haz clic en **Save**

Tu sitio estará disponible en: `https://TU_USUARIO.github.io/la-biblia-abierta/`
